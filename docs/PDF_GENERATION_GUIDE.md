# Инструкция по созданию PDF-генератора презентаций

> Полный технический справочник: [WEB_TO_PDF_STYLE_GUIDE.md](./WEB_TO_PDF_STYLE_GUIDE.md)
> Переиспользуемые компоненты: `/app/frontend/src/components/pdf-shared/PdfComponents.jsx`

## Общие принципы

PDF — это **адаптация** веб-версии под формат печати A4 Landscape, а не её точная копия.
Экран компьютера (16:9) и страница A4 Landscape (~1.414:1) имеют разные пропорции.
Задача: передать тот же контент и визуальный стиль, но с учётом размеров бумаги.

---

## 1. Размеры и отступы

| Параметр | Значение | Примечание |
|---|---|---|
| Страница | 841.89 × 595.28 pt | A4 Landscape |
| Отступы (padding) | 36pt по бокам, 30pt сверху/снизу | Контентная область: ~770 × 535 pt |
| Заполнение страницы | **минимум 70%** | Контент должен занимать не менее 70% площади |

---

## 2. Шрифты — размерная сетка

Все шрифты крупнее чем в веб-версии. Минимальный шрифт в PDF — **10pt**.

| Элемент | Размер PDF | Вес | Пример |
|---|---|---|---|
| Заголовок слайда (h1/h2) | **36pt** | 700 | «Как мы работаем» |
| Подзаголовок | **14–16pt** | 400 | «От замера до демонтажа» |
| Заголовок карточки | **14–18pt** | 700 | «Наталья Ромашова» |
| Основной текст | **12–14pt** | 400 | Описания, абзацы |
| Текст в карточках | **11–12pt** | 400 | Пункты списков |
| Подпись/источник | **10pt** | 400 | «NZR, 2018» |
| Номер слайда / бренд | **8–11pt** | 700 | «01 / 10», «СДЕЛАЙ КРАСИВО» |
| Бейджи (теги) | **10pt** | 700 | «ДЕКАБРЬ», «ПРЕМИУМ» |

### Правило: никогда не использовать fontSize < 10pt в PDF

---

## 3. Максимум элементов в строке

Длина русских слов в среднем 6–12 символов, но встречаются слова 14–20 символов
(«Профессиональная», «Согласование», «Переоформление»).

| Ширина элемента | Макс. элементов в строке | Мин. ширина элемента |
|---|---|---|
| Контентная область ~770pt | — | — |
| Крупные карточки | **3–4** в строке | ≥ 170pt |
| Средние карточки | **4** в строке | ≥ 170pt |
| Мелкие карточки | **4** max в строке | ≥ 170pt |

### Правило: максимум 4 карточки в строке. Если элементов > 4 — разбивать на 2 ряда.

**Расчёт**: 770pt контентной ширины / 4 элемента − gaps = ~180pt на карточку.
При 5+ элементах в строке: 770 / 5 − gaps = ~142pt — слишком мало для русского текста.

---

## 4. Картинки

### Обязательный паттерн: imgBase

Картинки в PDF загружаются по абсолютным URL. Относительные пути не работают.

```jsx
// В компоненте слайда — принимать imgBase как пропс:
const S8 = ({ imgBase }) => (
  <Image src={`${imgBase}/images/mb/kp-photo-1.jpeg`} />
);

// При вызове — передавать origin + PUBLIC_URL:
const imgBase = window.location.origin + (process.env.PUBLIC_URL || '');
<MBDoc imgBase={imgBase} />
```

### Размеры картинок
- Одиночная картинка рядом с текстом: `width: 200–240, height: 280`
- Картинки в сетке (4 в ряд): `width: "100%", height: 280`
- Всегда `objectFit: "cover"`, `borderRadius: 8`

---

## 5. Шрифты — регистрация

### Обязательно регистрировать ВСЕ используемые начертания

```jsx
Font.register({
  family: "Inter",
  fonts: [
    { src: "...ttf", fontWeight: 400 },
    { src: "...ttf", fontWeight: 600 },
    { src: "...ttf", fontWeight: 700 },
    // Если нужен italic:
    { src: "...ttf", fontWeight: 400, fontStyle: "italic" },
  ],
});
```

### Правило: НЕ использовать `fontStyle: "italic"` без регистрации italic-шрифта
Ошибка `Could not resolve font` — крашит весь PDF.

---

## 6. Запрещённые паттерны

| Паттерн | Почему плохо | Что делать |
|---|---|---|
| `flex: 1` на карточках | Растягивает на всю высоту страницы | Убрать, использовать фиксированную высоту или auto |
| `justifyContent: "center"` на странице | Контент уезжает в центр, 50% пустоты | Использовать только для Cover и CTA слайдов |
| `height: "100%"` на карточке | Растягивает до края страницы | Использовать `auto` или конкретное значение |
| 5+ карточек в строке | Текст обрезается | Максимум 4 в строке, остальные — на следующий ряд |
| `fontStyle: "italic"` без регистрации | Крашит PDF-генерацию | Зарегистрировать italic или не использовать |
| Относительные пути к картинкам | Картинки не загружаются | Использовать imgBase (абсолютный URL) |
| fontSize < 10pt | Нечитаемо при печати на A4 | Минимум 10pt |

## 7. Общие компоненты (переиспользуемые)

Хранятся в `/app/frontend/src/components/pdf-shared/PdfComponents.jsx`.
Импортируются в каждый PDF-генератор.

### Список компонентов:
- `Header({ label, num, total })` — верхняя строка слайда (лейбл + номер)
- `Brand({ text, accentText, color })` — нижний левый бренд
- `Dot({ size, color })` — точка-маркер для списков
- `Badge({ children, solid, color })` — тег/бейдж
- `Card({ children, accentBorder, style })` — карточка с фоном и бордером
- `Divider({ width, color, mt, mb })` — разделитель
- `registerInterFont()` — регистрация шрифта Inter (400, 600, 700)

### Цветовые токены (передаются как пропс `theme`):
```js
{
  bg, bg2, fg, fg2, muted, dim,
  accent, accent2, accentBg,
  border, border2
}
```

## 8. Структура PDF-генератора для новой презентации

```
/app/frontend/src/components/НоваяPdfGenerator.jsx
```

```jsx
import { Header, Brand, Card, Badge, Dot, Divider, registerInterFont } from './pdf-shared/PdfComponents';

// 1. Регистрация шрифтов
registerInterFont();

// 2. Тема (цвета)
const T = { bg: "#0a0a0a", accent: "#2d9b6a", ... };

// 3. Размеры страницы
const PW = 841.89, PH = 595.28, PX = 36, PY = 30;

// 4. Слайды (каждый — отдельный <Page>)
const S1 = ({ imgBase }) => ( <Page size={[PW, PH]} style={...}> ... </Page> );

// 5. Документ
const Doc = ({ imgBase }) => (
  <Document>
    <S1 imgBase={imgBase} /> <S2 /> ...
  </Document>
);

// 6. Экспорт
export async function generatePdf(onProgress) {
  const imgBase = window.location.origin + (process.env.PUBLIC_URL || '');
  const blob = await pdf(<Doc imgBase={imgBase} />).toBlob();
  // ... скачивание
}
```

## 9. Чек-лист перед сдачей PDF

- [ ] Все шрифты ≥ 10pt
- [ ] Заголовки слайдов 36pt
- [ ] Контент заполняет ≥ 70% страницы
- [ ] Максимум 4 карточки в строке
- [ ] Картинки через imgBase (абсолютный URL)
- [ ] Нет `fontStyle: "italic"` без регистрации
- [ ] Нет `flex: 1` на карточках
- [ ] Нет `height: "100%"` на карточках
- [ ] `justifyContent: "center"` только на Cover и CTA
- [ ] Все русские слова помещаются в карточки (проверить длинные слова)

## 10. История ошибок (чтобы не повторять)

Каждая ошибка ниже реально случалась при создании презентаций. НЕ ПОВТОРЯТЬ.

| # | Ошибка | Симптом | Причина | Решение |
|---|---|---|---|---|
| 1 | `fontStyle: "italic"` | PDF не генерируется, ошибка в консоли | Курсивный вариант шрифта не зарегистрирован | Убрать italic или зарегистрировать italic-шрифт |
| 2 | 7 карточек в одну строку | Слова обрезаются («Согласовани», «Профессиональна») | Ширина карточки < 130pt, русские слова не помещаются | Максимум 4 в строке, остальные — следующий ряд |
| 3 | `flex: 1` на карточке | Карточка растянута на всю высоту, 70% пустоты | Flexbox растягивает дочерний элемент | Убрать flex: 1, использовать натуральную высоту |
| 4 | `height: "100%"` | Правый блок растянут до низа страницы | Явная высота 100% от родителя | Убрать, использовать auto или фиксированное значение |
| 5 | `justifyContent: "center"` на странице | Контент в центре, 50% страницы пусто | Центрирование работает когда контента мало | Использовать только на Cover/CTA, остальные — top-aligned |
| 6 | Относительные пути к картинкам | Картинки не отображаются в PDF | @react-pdf не резолвит `/images/...` | Передавать imgBase = `window.location.origin + PUBLIC_URL` |
| 7 | fontSize 8–9pt | Текст нечитаем при печати | Слишком мелко для A4 | Минимум 10pt, заголовки 36pt |
| 8 | Заголовки 28pt | Слайд выглядит пустым, текст мелкий | Недостаточно крупно для A4 landscape | Заголовки 36pt |
| 9 | Бейдж не центрирован | «СЕЗОННЫЙ ДЕКОР» прижат к левому краю на Cover | `alignSelf: "flex-start"` на бейдже | Обернуть в `<View style={{ alignItems: "center" }}>` |
| 10 | SVG декорация больше страницы | Лишние пустые страницы в PDF | SVG width/height > content area с учётом padding | Ограничить SVG контейнером 300×300 с overflow: hidden |
